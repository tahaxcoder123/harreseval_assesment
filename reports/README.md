# Evaluation Reports & Artifacts (`reports/`)

The `reports/` directory contains evaluation outputs, comparison reports, and raw audit artifacts generated by `harness-eval evaluate`.

---

## 1. Directory Structure

```text
reports/
└── sample/
    ├── report.html              # Standalone interactive HTML report (single file, dark mode)
    ├── report.json              # Complete versioned schema dump (SCHEMA_VERSION = "1.0.0")
    ├── summary.json             # Compact executive summary for CI/CD checks & PR comments
    └── runs/                    # Task-level execution artifacts & raw evidence
        ├── task-01/
        │   ├── baseline.patch       # Unified diff generated by baseline harness
        │   ├── candidate.patch      # Unified diff generated by candidate harness
        │   ├── baseline_run.json    # Complete baseline run metadata & pytest logs
        │   ├── candidate_run.json   # Complete candidate run metadata & pytest logs
        │   └── comparison.json      # Structured task-level delta & evidence points
        ├── task-02/
        └── ...
```

---

## 2. Report Formats & Artifacts

### 1. Interactive HTML Report (`report.html`)
- **Self-Contained**: Requires zero external CSS or JavaScript CDN dependencies.
- **Modern Dark-Mode UI**: Features styled metric cards, collapsible task accordions, side-by-side metric deltas, and color-coded status badges.
- **Diff Viewer**: Displays syntax-highlighted unified patch diffs (`.diff-add` and `.diff-rem`) directly within the browser.
- **Portable**: Can be zipped, emailed, or served statically in CI build pipelines without breaking styles.

### 2. Versioned JSON Report (`report.json`)
- Conforms to Pydantic schema [`ComparisonReport`](file:///d:/Task/chat/src/harness_eval/models.py) with `schema_version: "1.0.0"`.
- Contains complete benchmark suite metadata, harness diff configurations, aggregate metrics, individual task comparisons, and decision policy outputs.
- Used for downstream data warehouses, dashboards, and automated analysis pipelines.

### 3. Compact CI Summary (`summary.json`)
- Lightweight JSON file specifically designed for GitHub Actions / GitLab CI comments:

```json
{
  "schema_version": "1.0.0",
  "timestamp": "2026-09-26T12:29:05.123456+00:00",
  "decision": "INCONCLUSIVE",
  "verdict": "Promising correctness gain, but inconclusive due to resource trade-offs or sample size.",
  "tasks_evaluated": 6,
  "repetitions": 1,
  "deltas": {
    "Correctness Rate": {
      "baseline": 0.3667,
      "candidate": 1.0,
      "absolute_delta": 0.6333,
      "relative_delta_pct": 172.73
    },
    "Average Cost ($)": {
      "baseline": 0.0091,
      "candidate": 0.0328,
      "absolute_delta": 0.0237,
      "relative_delta_pct": 260.44
    }
  },
  "trade_offs": [
    "Cost increased by +260.4% ($0.0091 -> $0.0328/task).",
    "Sample size (N=6) is below threshold of 10 tasks for statistical certainty."
  ]
}
```

### 4. Task Audit Patches (`runs/<task_id>/*.patch`)
Every task run preserves the exact unified git diff generated by the agent. This allows engineers to conduct manual code reviews of generated solutions:

```bash
# View the candidate patch for task-01
cat reports/sample/runs/task-01/candidate.patch
```

## 3. Auditing via CLI (`inspect`)

Use `harness-eval inspect` to review raw evidence and diffs from the terminal without opening JSON or HTML files:

```bash
harness-eval inspect task-01 --output reports/sample
```
